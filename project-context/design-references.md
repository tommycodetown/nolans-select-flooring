# Nolan Select Flooring — Design References

These references are inspiration, not templates to copy literally. The goal is to combine the strongest relevant ideas into one coherent design system for Nolan Select Flooring.

## 1. Customer.io

Refero:
https://styles.refero.design/style/abbaa70a-5fe2-44a9-9c5f-272e68c450c3

Website:
http://customer.io

### What I like
- The general layout and overall feel.
- The page has a strong sense of structure and visual rhythm.

### What I would change
- Some sections feel too large.
- Nolan Select Flooring should generally have tighter section heights and avoid unnecessary empty space.

## 3. OPX Studio

Refero:
https://styles.refero.design/style/bd395e2e-58a8-4626-acfa-9be8d6cdf604

### What I like
- The way project imagery alternates from left to right.
- The less predictable, editorial image compositions.

### Potential Nolan Select Flooring application
For the Featured Projects section, explore a layout where each project has:

- One dominant/main image.
- 2–4 supporting images alongside it.
- Supporting images arranged in varied sizes and shapes rather than a simple stack or uniform grid.
- Alternating compositions between projects — e.g. main image left for one project, main image right for the next.

The result should feel deliberately composed and architectural, not like a standard gallery grid.
